Attributions and Sources

Credits and resource information for the Nigerian Travel Guide educational website.

About the website

This website is a student project about travel destinations in Nigeria. Its destination descriptions are short educational summaries, not live travel advisories. Opening hours, accessibility, entry fees, and transport arrangements should be confirmed directly with destination operators before a visit.

Destination information

The destination listings are maintained in data/destinations.json. The website uses locally stored destination names, states, categories, locations, and summaries to create searchable cards. These descriptions are project content, not quotations from a published travel guide.

Images and graphics used

The following image files are included in this project. All images used in this website are openly sourced and license-free, with no ownership should not be assumed.

  • images/welcome-nigeria.webp — Abuja City Gate image on the home page.
  • images/idanre-hills.webp — Idanre Hills image on the home page.
  • images/erin-ijesha.webp — Erin-Ijesha Waterfalls image on the home page.
  • images/national-museum.webp — National Museum image on the home page.
  • images/ng.webp — Nigerian flag graphic in the navigation.
  • images/favicon.ico and images/favicon.svg — generated on favicon.cc website .

Headings use Poppins, and body text uses Inter. Both are delivered through Google Fonts links in the HTML document heads rather than CSS imports.

Technical resources

JavaScript features use built-in browser technologies: the Fetch API, localStorage, and the HTML dialog element. The site does not depend on a third-party JavaScript framework.

Corrections and source details

If you recognize an image source or need to request a credit correction, please contact the website owner through the email address. Attribution does not replace the need to obtain appropriate permission to reuse an image.
